# Logon System

Laboratório de **Authentication & Application Security** em Node.js para estudar fluxos de login, validação, sessão e controles defensivos.

## Objetivo
Praticar uma implementação pequena e compreensível onde autenticação não seja tratada apenas como formulário, mas como fronteira de segurança.

## Foco
- secure login flow;
- password handling;
- session security;
- brute-force resistance;
- account enumeration resistance;
- audit logging;
- security testing.

O projeto é educacional. Credenciais, tokens e dados reais não devem ser adicionados ao repositório.
